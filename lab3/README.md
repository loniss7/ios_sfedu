# Виселица — SwiftUI

Лабораторная работа 3 переносит игру «Виселица» из `lab1` в односценовое iOS-приложение.

## Запуск

Откройте `CompetitiveHangman.xcodeproj` в Xcode, выберите iPhone или iPad Simulator и запустите схему `CompetitiveHangman`.

## Игра

Кнопка запускает автоматическую партию из пяти раундов между Alice и Bob. На экране отображаются правила, текущий счёт, текстовый журнал ходов и итоговый победитель. Ошибки показываются ASCII-этапами в журнале; отдельная графическая сцена игры не используется.

Игровой движок, стратегии, словарь и правила скопированы из `../lab1/CompetitiveHangman/CompetitiveHangman.playground/Sources`. UI подписывается на `GameEvent` через Observer, поэтому игровой код не зависит от SwiftUI и не печатает в консоль.

## Адаптация интерфейса

Экран использует прокручиваемую вертикальную разметку, карточки с адаптивной сеткой и ширину контента с верхним ограничением. На узких iPhone карточки располагаются в один столбец; на широких экранах сетка использует доступное место. Цвета основаны на системных цветах iOS и поддерживают светлую и тёмную темы.
